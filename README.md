# 0summer0 DSH plugin market

A [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) plugin-market index (format 1) for plugins published by **0summer0**.

## Use this index in DSH

1. Open **Plugins → Discover** (enable the experimental **Custom plugin indexes** bundle first if the tab is missing).
2. Choose **Add index source** and enter:

   ```
   https://0summer0.github.io/dsh-plugin-market/index.json
   ```

3. Browse the listed bundles and install one after confirming its source.

## Indexed plugins

| Plugin | What it does |
|---|---|
| `dsh-skill-icp-exemption` | Drafts and generates the bilingual Apple App Store China ICP filing exemption declaration (`ICP 备案豁免申请声明`) PDF for one standalone iOS app. |

Source, issues, and releases for the first entry live in [0summer0/dsh-skill-icp-exemption](https://github.com/0summer0/dsh-skill-icp-exemption).

## Notes

- Index content is third-party data: DSH validates the file format but does not verify the claims in it. Review an entry's source before installing.
- This repository only hosts the index and its icons; the plugin packages are installed from the sources the index names.
- The index is served with GitHub Pages from the repository root.
